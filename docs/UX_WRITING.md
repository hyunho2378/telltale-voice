# 화면 문구 기준 (2026. 11. 15.)

실제 현대차와 기아, 제네시스 차량의 클러스터 메시지, 인포테인먼트 화면, 사용 설명서, 마이현대와 블루링크 서비스 문구를 읽고 정한 기준이다. 화면에 들어가는 낱말은 이 문서의 "바꾼 문구" 열이 기준이다.

## 1. 읽은 자료와 거기서 나온 규칙

## 2. 쓰는 규칙

1. 화면 이름과 타일 이름은 명사 하나나 "명사 + 명사"다. 동사로 끝내지 않는다. 눌러서 하는 일은 "찾기", "요청", "추가"처럼 동작 낱말로 끝낸다.
2. 상태는 "켜짐", "꺼짐", "정상", "점검 필요", "확인 중", "확인 불가"처럼 두세 글자 명사로 쓴다. 문장으로 쓰지 않는다.
3. 위험 설명은 현대 표의 열 이름 "원인"과 "조치 방법"을 그대로 쓴다. 조치 방법 문장은 설명서 원문 "~하십시오"다.
4. 시간 순서는 "후"로 쓴다("정차 후", "도착 후").
5. 정비소는 "서비스센터"로 부른다. 현대차는 "하이테크센터", "블루핸즈"를 쓰고, 화면에 정비소 이름이 들어갈 때는 이름 그대로 보인다.
6. 사람에게 말을 거는 문장("~드립니다", "~시험이 끝났습니다.", "곧 시작합니다.")은 화면에 쓰지 않는다. 안내는 음성이 맡는다.
7. 시험과 시연을 뜻하는 낱말("시험", "시연")은 화면에 쓰지 않는다. 다섯 장면을 미리 듣는 화면은 "음성 미리 듣기"라고 부른다.
8. 이 앱만의 말("도감", "이번 운전", "그때")은 쓰지 않는다. 같은 일을 하는 현대차 화면 낱말로 바꾼다.
