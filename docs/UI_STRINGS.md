# 화면 문자열 목록 (2026. 11. 15., docs/UX_WRITING.md 3절 기준)

화면 코드가 직접 쓰는 문자열을 화면별로 적었다. { } 안은 값이 들어가는 자리다. 엔진이 넘겨주는 글(음성 경고 문장, 설명서 원인과 조치 방법, 판정 라벨, 경고등 이름, 시각 줄)은 맨 아래에 출처만 적었다.

## 왼쪽 메뉴
- 홈, 경고등 정보, 경고 이력, 설정
- 메뉴 아래 차 그림 판: 경고등 없음, 또는 {경고등 이름} / 켜짐

## 홈 (차량 상태)
- 제목: 차량 상태, 오른쪽 위: 마지막 확인 / {오후 2:33}
- 경고등 / 없음, 또는 {경고등 이름} / 켜짐
- 경고 음성 안내 / 켜짐 또는 꺼짐
- 구역 이름: 출발 전 점검
- 점검 다섯 칸: 타이어 공기압, 엔진 오일, 브레이크액, 와셔액, 연료 / 정상, 점검 필요, 확인 중, 확인 불가, 또는 엔진 값(저압, 64% 등)
- 서비스센터 찾기 / {서비스센터 이름} {7.5km}, 또는 서비스센터 찾기 / 확인 중
- 최근 이력 / {경고등 이름}, {오전 9:36 켜짐} 또는 없음

## 출발 전 점검 상세
- 메뉴 맨 위: 출발 전 점검(돌아가기)
- 제목: {항목 이름}, 큰 글: {상태 값}, 회색 줄: {설명서 원인}
- {관련 경고등 이름} / 켜짐 또는 꺼짐, 서비스센터 찾기
- 조치 방법 / 1 {설명서 문장} ..., 아래 칸: 최근 켜짐 / {시각} 또는 없음

## 경고 이력
- 제목: 경고 이력, 오른쪽 위: 마지막 확인 / {시각}
- 두 건 이하: 경고등 / 없음 또는 이력 칸, 서비스센터 찾기, 이력 / {0}건, 마지막 확인, 경고등 정보(상태 줄 없음), 설정
- 이력 칸: {경고등 이름} / {오전 9:36 켜짐, 9:53 꺼짐}

## 경고 이력 상세
- 메뉴 맨 위: 경고 이력(돌아가기)
- 제목: {경고등 이름}, 큰 글: 켜짐 또는 꺼짐, 회색 줄: {시각 줄}
- 켜진 시각 / {오전 9:36}, 꺼진 시각 / {오전 9:53} 또는 켜짐
- 안내 문장 / {그 경고 때 말한 문장} 또는 없음, 주행 도로 / {국도 7호선}
- 조치 방법 / 1 {설명서 문장} ..., 아래 칸: 서비스센터 찾기

## 경고등 정보
- 메뉴 맨 위: 홈(돌아가기), 그 아래 경고등 이름 목록
- 제목: 경고등 정보, 세그먼트: 빨강 {8}, 노랑 {14}, 초록과 파랑 {9}
- 큰 타일: {빨강} 경고등 / {경고등 이름} / {판정 라벨}
- 원인 / {설명서 문장}
- 조치 방법 / 1 {설명서 문장} ... 또는 없음, 아래 칸: 최근 켜짐, 서비스센터 찾기

## 설정
- 제목: 설정
- 음성: 경고 음성 안내 토글 / 켜짐 또는 꺼짐
- 일시 정지한 안내 / 없음, 또는 {경고등 이름} 해제, 모두 해제
- 다시 듣기 / 마지막 안내, 음성 미리 듣기 / {오후 2:33} 재생(들은 적 없으면 상태 줄 없음), 경고등 정보(상태 줄 없음)
- 최근 이력, 서비스센터 찾기, 마지막 확인 / {시각}

## 음성 미리 듣기
- 메뉴 맨 위: 설정(돌아가기)
- 제목: 음성 미리 듣기
- 다섯 칸: 엔진 오일 압력 / 저압 타이어, 시내 / 저압 타이어, 고속도로 / 엔진 점검 / 브레이크액, 고속도로. 상태: {판정 라벨}, 재생 후에는 {오후 2:33} 재생
- 여섯째 칸: 마지막 재생 / {오후 2:33} 또는 없음

## 음성 미리 듣기 재생 화면
- 메뉴: 닫기, 다섯 장면 이름과 판정 라벨, 경고 음성 안내 / 안내 중 또는 대기, 마지막 확인 / {시각}
- 제목: {장면 이름}, 회색 줄: 음성 미리 듣기, 오른쪽 위: 음성 안내 중, 대기, 재생 끝
- 큰 타일: {판정 라벨} / {경고등 이름}
- 갈 곳: 서비스센터 찾기 / {이름} {거리}, 앞쪽 휴게소 / {12km}, 정차 자리 / 도로 옆 안전한 곳
- 다시 듣기 / 마지막 안내
- 재생 중 / {음성 문장}, 없을 때 대기 또는 재생 끝
- 다음 안내 / 1 주행 중 음성 안내, 2 정차 후 안내 또는 도착 후 점검 또는 고속도로 대피 안내
- 아래 단추: 정지, 처음부터, 다음 장면. 경유지 질문 때: 경유지 추가, 취소

## 주행 중 안내 (정차 후 첫 화면과 같은 틀)
- 위 줄: 닫기(미리 듣기 중일 때만), 음성 안내 중 또는 대기
- 큰 타일: {판정 라벨} / {경고등 이름} / {행동 한 줄}, 오른쪽 위 표시: {오전 9:36 켜짐}
- 즉시 정차 경고: 견인 요청 / 한국도로공사 1588-2504, 그 밖: 갈 곳
- 다시 듣기 / 마지막 안내
- 경유지 질문 때: 경유지 추가, 취소

## 정차 후 안내 (첫 화면)
- 위 줄: 닫기, 정차 후 안내 또는 도착 후 점검 안내
- 경고등이 둘 이상이면 세그먼트: {경고등 이름}
- 큰 타일: {판정 라벨} / {경고등 이름} / {행동 한 줄}, 오른쪽 위 표시: {오전 9:36 켜짐}
- 다음 행동: 즉시 정차면 견인 요청 / 한국도로공사 1588-2504, 그 밖은 서비스센터 찾기 / {이름} {거리}
- 자세히 보기 / 원인과 조치 방법

## 정차 후 안내, 자세히
- 위 줄: 닫기, 자세히
- 견인 요청 또는 서비스센터 찾기(첫 화면에 없던 쪽), 보험사 긴급출동 / 가입한 보험사, 다시 듣기 / 마지막 안내
- 켜진 시각 / {오전 9:36 켜짐}, 안내 일시 정지 / 해제 또는 정지, 원인 / {설명서 문장}
- 조치 방법 / 1 {설명서 문장} ...

## 고속도로 대피
- 메뉴: 닫기, 비상등 켜기, 트렁크 열기, 가드레일 밖 대피, 견인 요청(각 대피 {1}단계), 경고 음성 안내, 마지막 확인
- 제목: 고속도로 대피 안내, 회색 줄: 대피 {3}단계, {가드레일 밖 대피}
- 큰 타일: 대피 {3}단계 / {엔진 대피 문장}, 오른쪽 위 표시: 4단계 중 {3}단계
- 견인 요청 / 한국도로공사 1588-2504, 자세히 보기, 펼친 후 닫기
- 펼침: 보험사 긴급출동 / 가입한 보험사, 갈 곳, 다시 듣기, 다음 단계 / {트렁크 열기} 또는 마지막 단계 / 가드레일 밖 대기

## 엔진이 넘겨주는 글 (화면 코드에 없음)
- 음성 경고 문장: core SpeechBuilder, 목록은 docs/VOICE_LINES_2027.md
- 판정 라벨: core DecisionRule.label (즉시 정차, 휴게소까지 서행, 서비스센터까지 서행, 안전한 곳에서 점검, 휴게소까지 주행 가능, 도착 후 점검)
- 경고등 이름, 원인, 조치 방법: core LampCatalog와 Catalog95(2027 그랜저 설명서 원문)
- 시각 줄: core LampTimeText와 화면 LampTime(오전 9:36 켜짐, 오전 9:36 켜짐, 9:53 꺼짐)
- 출발 전 점검 값: core PreTripItem.valueText(정상, 점검 필요, 확인 불가, 저압 등)
