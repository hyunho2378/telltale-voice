# 판정 정확성 대조 (2026. 11. 15.)

경고등 분류표(core LampCatalog)와 판정 규칙(core DecisionRules), 경고등 정보(core Catalog95)을 2027 그랜저(GN7) 웹 취급설명서 원문(core ManualGN7, 설명서 "경고등 및 표시등 확인하기" 37개 항목과 TPMS, 엔진 과열 쪽)과 한 줄씩 대조한 기록이다. 괄호 숫자는 설명서 항목 번호다.

## 고친 어긋남

| 번호 | 어긋남 | 설명서 원문 | 고친 내용 | 고정한 시험 |
|---|---|---|---|---|
| 1 | 휴게소까지 갈래의 기본 판정 문장이 "설명서가 속도를 낮추라고 하는 경고등"이라고 적었다. 이 규칙을 쓰는 전동 파워 스티어링 (3)과 연료 부족 (12), EBD (9) 원문에는 속도를 낮추라는 문장이 없다 | (9) "차체가 불안정할 수 있으므로 고속 주행을 피하십시오." (3), (12) 정차와 감속 지시 없음 | 문장을 "설명서가 정차를 지시하지 않는 경고등이라 앞쪽 휴게소까지 주행을 안내합니다."로 바꿨다. 속도를 낮추라는 문장은 원문에 있는 저압 타이어 두 규칙에만 남겼다 | DecisionAudit2027Test 휴게소까지 기본 규칙 문장, 저압 타이어 두 규칙 |
| 2 | EBD 경고등이 분류표에 있는데 켜짐을 판단하는 경로가 없어 한 번도 켜지지 않았다 | (9) "브레이크 경고등과 ABS 경고등이 동시에 켜진 경우, 제동력의 전후륜 배분 기능(EBD)도 정상적으로 작동하지 않습니다." | 브레이크 경고(브레이크액 수준)와 ABS가 함께 켜지면 EBD도 켜진 것으로 본다 | DecisionAudit2027Test EBD, ResolverTest 여러 경고 동시에 |
| 3 | 경고등 정보에서 조치 방법 문장이 없는 상태 표시등에 엔진 갈래(도착 후 점검)가 실렸다. (29) 차로 유지 보조 표시등은 초록과 회색만 있고 고장 상태가 없다 | (29) "초록색: 차로 유지 보조 작동 중", "회색: 차로 유지 보조 준비 상태" | 설명서 항목에 "~십시오" 문장이 없는 상수는 경고등 정보에서 갈래와 분류표 짝을 싣지 않는다 | DecisionAudit2027Test 상태 표시등 |
| 4 | LPG 과충전 경고등 (5)이 빨간 경고등인데 분류표에 없어 Pleos 상수 LPI가 켜져도 음성 안내가 나가지 않았다 | (5) "LPI 차량은 LPG가 과충전 되었을 경우 빨간색으로 경고등이 켜집니다.", "경고등이 켜지면 당사 직영 하이테크센터나 블루핸즈에서 차량을 점검하십시오." | 분류표에 LPG_OVERCHARGE를 더했다. 원문에 정차 지시가 없고 점검 지시만 있어 충전 경고등 (4)과 같은 휴게소까지 갈래로 두고, 판정 라벨은 "안전한 곳에서 점검"(규칙 RED_CHECK)으로 맞췄다. 음성은 "LPG 과충전 경고등이 켜졌습니다. 블루핸즈에서 차량을 점검하십시오." | CatalogGoldenTest 분류표 22개와 갈래별 개수, DecisionBasisTest 기본 판정 규칙, ManualConsistencyTest 19개 경고등 |

## 대조해서 어긋나지 않은 항목

| 항목 | 확인한 내용 |
|---|---|
| 즉시 정차 갈래 4종 | 엔진 오일 압력 (6), 냉각수 수온 (7, 엔진 과열 쪽), 브레이크 (8), ABS (10)만 원문 행동 문장에 정차 지시가 있다. 다른 경고등 행동 문장에는 정차 지시가 없다. 시험이 "원문에 정차 지시가 있는 경고등과 즉시 정차 갈래가 정확히 같음"을 고정한다 |
| 저압 타이어 도로별 판정 | 고속도로는 앞쪽 휴게소, 일반도로는 가까운 정비소다. 두 문장의 "속도를 낮춰"는 TPMS 쪽 원문 "속도를 낮추고 급격한 조향을 피하며"에 있다. 일반도로에서 정비소를 고르는 근거도 같은 쪽 "블루핸즈에서 타이어 상태를 점검한 후"다 |
| 충전 경고등 | (4)에 정차 지시가 없어 휴게소까지 갈래이고 라벨은 "안전한 곳에서 점검"이다 |
| TPMS 두 갈래 | (13) "약 1분간 깜빡인 후 켜지면" 이상으로 보고, 깜빡임 없이 켜지면 저압으로 본다 |
| 깜빡임이 정상 작동인 표시등 | ESC (20)는 "ESC 제어 기능 작동 중 깜빡입니다"라 켜짐만 이상으로 본다. 자동 정차 (16)은 "주황색: 자동 정차 기능 이상 발생"이라 주황색만 이상으로 본다 |
| 경고등 정보 색 묶음 | 설명서 표의 아이콘 색을 그대로 쓰고, 표에 색이 없으면 본문의 초록색과 파란색만 쓴다. 색이 적혀 있지 않은 도로 결빙 (36)은 경고등 정보에서 숨긴다 |
| 원인과 조치 방법 문장 | 경고등 정보와 정차 후 화면이 같은 함수(ManualGN7.meaning, ManualGN7.actions)를 읽어 두 화면 문장이 늘 같다. 분류표 19개 경고등의 모든 문장이 설명서 원문 줄에 그대로 있다 |

## 분류표에 넣지 않은 설명서 경고등과 까닭

| 설명서 항목 | 까닭 |
|---|---|
| (1) 안전벨트 미착용 경고등 | 차량 고장 경고가 아니다. 설명서 조치는 안전벨트 착용뿐이고 차량이 이미 경고음을 낸다. 경고등 정보에는 싣는다 |
| (18) 키 확인, (28) 도어 열림, (36) 도로 결빙 | 고장이 아닌 상태 안내다. 설명서에 정비 조치가 없거나 운전자가 바로 처리할 상태다. 경고등 정보에는 싣는다 |
| (21) ESC 작동 정지, (25) 지능형 속도 제한 보조, (26) 전방 주시, (27) 부주의 운전 | 기능 꺼짐과 작동 중 표시가 같은 등을 쓴다. 고장 상태만 골라내는 색과 상태 조건이 설명서에 갈리지 않아 음성 안내 대상에서 뺀다. 경고등 정보에는 싣는다 |
| (30) 고속도로 차로변경 보조, (31) 하이빔 보조, (32) 전조등 상향, (33) 미등, (34) 전조등 하향, (35) 비상 경고등과 방향지시등, (37) 시동 대기 | 작동 표시등이다. 설명서에 고장 조치 문장이 없다 |

## 남은 차이

| 항목 | 내용 |
|---|---|
| 운전자 보조 경고등의 원인 문장 | 분류표는 FCA와 LKA, LFA, ELK 네 상수를 "운전자 보조 경고등" 하나로 묶고 원인 문장을 전방 안전 (22)에서 읽는다. 경고등 정보는 상수마다 설명서 항목을 따로 짝지어 LKA는 차로 안전 (24)를 보여 준다. 같은 상수가 켜질 때 정차 후 화면과 경고등 정보의 원인 문장이 다를 수 있다. 음성과 화면 이름이 "운전자 보조 경고등" 한 이름이라 공통 문장을 (22)로 둔다 |
| 예열 표시등과 이모빌라이저 경고등 | 2027 그랜저 경고등 쪽에 항목이 없어 예전 판(투싼 NX4, 팰리세이드 LX3) 문장을 쓴다. 출처를 문장마다 따로 적는다 |
